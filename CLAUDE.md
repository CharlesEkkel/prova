## Agent skills

### Issue tracker

Issues and specs live as GitHub Issues on CharlesEkkel/prova, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Code style

Functional, immutable, strictly typed TypeScript with Effect in the shell. Follow `docs/agents/code-style.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
