# Contributing to Prova

Thanks for helping. Before you start:

- Read `CONTEXT.md` for the project vocabulary and use those terms in code and issues.
- Read `docs/agents/code-style.md` for the code style, lint rules and CI checks. Pull requests must pass lint, formatting, type checking and tests.
- Work is tracked as GitHub Issues. Pick one that is labelled `ready-for-agent` or `ready-for-human` and has no open blockers.
